# Beecrowd

> Repositório com meus exercícios de algoritmos resolvidos na plataforma **Beecrowd**, para estudo e prática de programação.

> Repository with my algorithm exercises solved on the **Beecrowd** platform, for learning and programming practice.

<br>

## Sobre/About

> Este repositório reúne todos os exercícios de lógica de programação e algoritmos que resolvi na plataforma Beecrowd. O objetivo é **praticar raciocínio lógico, estrutura de dados e técnicas de programação**, além de servir como registro do meu aprendizado.

> This repository brings together all the programming logic and algorithm exercises I solved on Beecrowd. The goal is to **practice logical reasoning, data structures, and programming techniques**, as well as to serve as a record of my learning.
